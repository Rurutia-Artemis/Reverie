# Reverie 视觉样稿 v2（2026-09-25）

主席看完 v1 三个方向后的意见：太简单、太初级，要调研后在甲「夜读」上重做。v1 存档在 `v1/`。

## 调研后借了什么（借做法，不借长相）

- 苹果手表活动圆环：同一来源的几项额度做成同心粗环，环带颜色渐变、末端圆头带投影；环底是同色的暗轨道。
- WHOOP 的表盘：纯黑底上的发光弧、彩色大数字，一眼能读出状态。
- 苹果 StandBy 与 iOS 播放页：大封面、封面颜色洇到背景里的氛围光、常驻的时间与日期。
- 车机播放页与海盗船 Xeneon Edge 副屏组件：分层的深色面板（顶部一道细高光）、胶囊形控制条、固定的顶栏。

## 这一版的结构

- 顶栏两页共用：左边是时间日期（额度页换成「额度 · 更新于 N 分钟前 · 提醒」），右边是「音乐 / 额度」切换胶囊，点它翻页。
- 音乐页：528 封面带封面色的柔光；右侧依次是来源、歌名、歌手 · 专辑、当前一句和下一句歌词、渐变进度条、胶囊控制条和红心。
- 歌词模式：封面缩到 360，五行歌词做主角，当前行 50px；进度和控制收到底部一条。
- 额度页：Claude 一块三环（5 小时、每周、Fable 每周），Codex 一块双环（每周、5 小时）；每项大数字是剩余百分比，环上的白点是「按时间应该剩下的位置」，数字在白点之前就是用得偏快；底部是重置时间线，标出每项什么时候恢复。

## 颜色

底 `#07080A`，面板 `#17181D → #0E0F12` 加 1px 顶部高光。Claude 系暖色：5 小时 `#FF9500→#FFC862`、每周 `#FF5A36→#FF9A6E`、Fable `#FF2D6F→#FF7AA2`；Codex 系冷色：每周 `#2F7BFF→#64D2FF`、5 小时 `#1FCF94→#7CF2C8`。提醒 `#FFC04D`，红心 `#FF375F`。音乐页氛围光取封面主色，本例珊瑚 `#FF8A5B`。

## 字体

拉丁与数字 SF Pro Rounded，中文圆体（Yuanti SC）。最小 24px，大数字 64px。
